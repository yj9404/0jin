## 구조

- 토스 앱인토스 WebView 미니앱(프런트엔드)과 API(백엔드)로 나뉜다. 조회는 로그인 없이 되고, 관심 회사만 앱인토스 익명 식별키로 사용자를 구분한다.
- 공공데이터포털의 국민연금 가입 사업장 내역 월별 CSV(약 59만 행)를 PostgreSQL에 적재한다. 같은 트랜잭션 끝에서 그달의 비교 통계(업종·규모별 연봉 중간값과 분포, 퇴사율 중간값)와 홈 요약을 계산한다.
- 회사 검색, 회사별 인원·입퇴사·추정 평균 연봉 추이, 두 회사 비교, 내 연봉 위치, 오늘의 연봉 퀴즈, 공유 이미지를 제공한다.
- OpenDART 사업보고서의 직원 현황과 공정위 지정 기업집단을 수집해 국민연금 사업장과 연결한다(사업자번호 앞 6자리와 이름).
- 과거 월 데이터는 국민연금 사업장 정보 OpenAPI로 나중에 채운다. 일일 호출 수를 DB에 기록해 한도를 지킨다.

## 기술 스택

- 프런트엔드: React 19, TypeScript, Vite, 앱인토스 SDK 3.x, 자체 디자인 토큰(CSS 변수)
- 백엔드: Python, FastAPI, psycopg(비동기), Pillow(공유 이미지), httpx
- DB·호스팅: PostgreSQL(`pg_trgm`), Railway
- 데이터: 국민연금공단 가입 사업장 내역(CSV·OpenAPI), OpenDART, 공정위 기업집단 API
- 인증: 앱인토스 익명 식별키 교환, 파트너 API mTLS

## 어려웠던 점

**추정 연봉 계산.** 가입자 수와 당월 고지금액으로 1인 월소득을 추정한다. 연금보험료율은 2026년 9.5%부터 해마다 0.5%p씩 올라 2033년 13%가 되고, 기준소득월액 상한은 매년 7월 바뀐다. 그래서 자료월 기준 상수 테이블로 계산하고, 추정 월소득이 상한의 95% 이상이면 "상한 이상"으로 표시한다.

**개인 노출 방지.** 가입자 10명 미만 사업장은 인원 수 외 지표(연봉·입퇴사·퇴사율)를 숨긴다. 30명 미만은 퇴사 1~2명으로 퇴사율이 크게 흔들려 규모 구간 비교를 하지 않는다.

**대용량 적재의 안전장치.** CSV를 스트리밍으로 읽어 `COPY`로 임시 테이블에 넣은 뒤 한 트랜잭션에서 upsert한다. 실패하면 전부 롤백된다. 행 수가 직전 적재의 90% 미만이면 잘린 파일로 보고 실패시킨다.

**사업장 식별.** 원본에 안정된 ID가 없어 `md5(사업자번호 앞 6자리|이름|가입일)`을 키로 쓴다. 같은 달에 키가 겹치면 법정동 코드를 붙인다.

**익명 사용자 저장.** anonKey 원문은 저장하지 않고, 서버 비밀값을 섞은 SHA-256만 저장한다.
